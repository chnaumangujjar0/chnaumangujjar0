### CareBase highlights

- **Tenant isolation:** tenant context is derived from the authenticated user, never trusted from the client.
- **Layered authorization:** authentication → tenant resolution → permission checks → controller.
- **Concurrency safety:** database transactions, per-stock locking, and appointment-overlap constraints.
- **Real-time updates:** Socket.IO rooms notify clients when a doctor's slots change.
